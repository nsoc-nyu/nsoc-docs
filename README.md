# NSOC Docs

Documents in this repo are built using [Typst][typst].

Install Typst in the appropriate way for your machine, then compile and watch documents following this example:

```
typst watch --font-path assets/fonts pitch.typ
```

You can then open `pitch.pdf` and it will live-reload as you make changes.
